  作業のおとも、棒人間
  作業集中用のポモドーロタイマー
  （棒人間が、デスクトップのウィンドウの上を歩きまわります）
  バージョン 1.0
────────────────────────────────────────

図や表の入った取扱説明書は、manual.htmlをブラウザで開いてください。


■ 30秒でわかる使い方

・BouTimer.exeを起動するだけで、25分の作業と5分の休憩が始まります
・棒人間を右クリック … メニュー（設定、やることリスト、今日の内訳など）
・頭の上の「▶作業24:59」をクリック … 一時停止と再開
・棒人間をドラッグ … つまんで運べます。勢いよく離すと投げます
・やめるときは、右クリックのメニューの「終了」


■ これは何か

棒人間が、デスクトップに開いているウィンドウの上の辺を足場にして歩きまわります。
25分の作業と5分の休憩をくり返すポモドーロタイマーの係でもあります。

・作業中は、ウィンドウからウィンドウへ飛び移ったり、お茶を飲んだり、釣りをしたり、縄跳びやヨーヨーで遊んだり、勝手にすごします
・休憩になると、いま使っているウィンドウのふちに飛んできて座ります
・作業中にサボり先（動画サイトなど）を開いていると、そのウィンドウまで来て「作業しようぜ～？」の札を出します
・今日のポモドーロ数、アプリ別の時間、打った回数を「今日の内訳」で見られます。1週間の記録も棒グラフで出ます
・やることリストのいちばん上のものを紙に書いて持ち歩きます。カーソルを乗せて出る札のチェック欄で、済みにできます
・決めた時刻になると、手前のウィンドウまで来て知らせます（会議や約束の時刻に）
・今日のまとめを、日報に貼れる文にしてコピーできます

操作はマウスだけです。キーボードの操作はありません。


■ 動作環境

・Windows 10 / Windows 11
・HSP 3.7で作成（実行にHSPは不要です）
・複数モニターに対応しています
・画面の拡大率（125%、150%など）に合わせて大きさを変えます
・音声の出力デバイスがない環境でも動きます（音楽に合わせて動く機能だけが働きません）
・記録と設定はBouTimer.exeと同じフォルダに置きます。そのフォルダに書きこめないとき（Program Filesに置いたときなど）は、%APPDATA%\BouTimerに置きます


■ はじめかた

BouTimer.exeを起動してください。インストールは不要です。
初めて起動したときは、「はじめまして」の小さな窓の中に棒人間がいて、いくつか質問します
（作業と休憩の長さ、打った回数を数えるか、サーバーと通信するか、Windowsの起動時に起動するか）。
ボタンで答えます。「スキップ」を押すと、ふつうの設定のまま始まります。質問ごとに、デフォルトの設定を下に出しています。答えたことは、設定画面でも変えられます。
終わると、棒人間が窓から飛び出して、使い方を少し話します。
タスクトレイ（画面右下）にアイコンが出ます。
見あたらないときは、タスクバーの「^」（隠れているインジケーター）の中にあります。

  頭の上でカーソルを左右に動かす … なでる
  右クリック ……… メニュー

デスクトップ（何もないところ）をダブルクリック … ウィンドウを渡ってそこまで来ます

■ やることリスト

メニューの「やることリスト…」で、やることを入れておくと、いちばん上のものを紙にして持ち歩きます。
キャラクターにカーソルを乗せると、持っているやることがチェック欄つきで見えます。
・札をクリックすると済みになり、紙を丸めてゴミ箱に投げ入れます。リストの「終わった！」ボタンでも同じです
・済みにしてから8秒のあいだは、札に「（もどす）」と出ます。もう一度クリックすると、まだに戻ります
・その日に済ませたものは、その日の絵日記と、今日のまとめにも書かれます
・追加してから終わるまでの時間を、リストと今日のまとめに「（35分）」のように出します
・今日の内訳には、今日終わった数と、かかった時間の平均が出ます
・todo.txtに保存します（「- 」で始まる行がまだのもの、「x 日付 」で始まる行が済んだもの。追加した時刻とかかった時間も同じ行に書きます）


■ 時刻を知らせる

メニューの「時刻を知らせる…」で、時・分・くり返しをプルダウンで選び、ひとことを添えて追加します。
くり返しは「1回だけ / 毎日 / 平日（月～金） / 土日 / 毎週○曜 / 毎月○日」から選べます
（毎週・毎月は、追加した日の曜日と日付になります）。
時刻になると、いま使っているウィンドウの上まで来て、時刻の札とひとことで知らせます。つつくと終わります。
「1回だけ」のものは知らせたら消えます。くり返しのものは一覧で選んで「選んだのを消す」で消せます。
全画面のアプリやプレゼンの最中は、終わってから知らせます。alarm.txtに保存します。


■ 今日のまとめ（日報用）

メニューの「今日のまとめをコピー（日報用）」で、次のような文をクリップボードに入れます。
そのまま日報やチャットに貼れます。

  10月16日（金）の作業
  作業2時間25分・ポモドーロ4サイクル
  タイピング5321打
  ウィンドウの切り替え6回

  終わったこと
  ・メールの返事

  残っていること
  ・資料の3章

  使ったアプリ
  ・code 1時間30分
  ・chrome 30分


■ 1週間の記録

「今日の内訳と1週間の記録」の下に、この7日間の作業時間を棒グラフで出します。今日の棒はオレンジ色です。
いちばん長くがんばった日の棒の上で、棒人間がばんざいしています。7日間に終わったやることの数も、合計の横に出します。
日ごとの合計はhistory.txtに60日分残します。


■ セリフを教える

メニューの「セリフを教える…」で、しゃべってほしいことばを入れると覚えます（20文字まで、50個まで）。
覚えたことばは、起動したときのあいさつのかわりや、ひまなときに言います。
kotoba.txtに1行1つで保存されます。「教えたセリフを編集…」で直したり消したりできます。


■ 季節のイベント

日付によって、帽子をかぶったり、その季節の動き（お正月の凧あげ、節分の豆まき、
七夕の短冊、お月見の団子など）をしたりします。
雪・桜・雨・落ち葉は、起動したときのあいさつと季節の動きのときだけ降ります。
メニューの「季節のイベント」を外すと、すべて止まります。


■ 認識の図示

メニューの「高度な設定」→「認識の図示」をオンにすると、画面全体に、いま足場として見えている辺、
手前のウィンドウに隠れている辺、ダブルクリックした場所までの経路、内部の値を重ねて表示します。
表示はクリックを素通しするので、そのまま作業できます。


■ 絵日記

日付が変わると、前の日の出来事（ポモドーロ数、使っていたアプリ、お茶、釣ったもの、
つつかれた回数など）から絵日記を1枚描いて、diaryフォルダにPNGで保存します。
絵の場面（20通りほど）や空の様子、文の言い回しは、その日の出来事と日付で変わります。
メニューの「今日の絵日記を描く」で、その日の分をいつでも描けます。
設定画面の「絵日記をすすめる時刻」（最初は21時）になると「絵日記、書くか？」と聞きます。つついて「書く！」を選ぶと描きます。
「しない」にすると聞きません。


■ フレンド（ゴースト）

メニューや設定画面で「サーバーと通信する（ゴースト機能用）」をオンにすると、ポモドーロを1つ終えるたびに
自分の記録を送り、休憩に入ると、ほかの参加者の棒人間が半透明のゴーストとして十数秒ほど遊びに来ます。
（参加者がまだいないときは、見本のゴーストが来ます）

送るのは、はじめて起動したときに作る匿名のID（16桁の英数字。settings.txtに保存）、線の色、
その日のポモドーロ数、作業した分数、よくやった動きの番号だけです。
名前、アプリ名、ウィンドウのタイトル、キー入力は送りません。数字以外の文字は置き場が受け付けません。
置き場（作者が用意したCloudflare Workers）は直近24時間・60人分だけを持ち、ほかの人に渡すときはIDも外します。
IPアドレスは保存しません（同じところから短い間に何度も送られたときに、はじくためだけに使います）。
置き場が混んでいたり止まっていたりしても、ゴーストが来ないだけで、ほかの機能はふつうに動きます。
最初は参加しない設定です。

フレンド：メニューの「フレンド…」に、自分のフレンドコード（8文字）が出ます。
相手のコードを入れて「追加」を押し、おたがいに登録すると、相手のその日のサイクル数と作業した分数が見えて、
休憩のときには、そのフレンドのゴーストが遊びに来ます（5人まで）。メッセージは送れません。
呼び名はこのPCの中だけのメモ（friends.txt）で、送りません。コードは匿名のIDから決まるので、記録を消して入れなおすと変わります。


■ 声

メニューや設定画面の「声」をオンにすると、決まったセリフを声に出し、声に合わせて口を動かします。
声は、VOICEVOX（https://voicevox.hiroshiba.jp/）で前もって作ったものを、voiceフォルダに入れてあります。
VOICEVOXを入れる必要はありません。数字の入るセリフは、決まった部分だけを声にします。
教えたセリフなど、入っていないものは声になりません。最初はしゃべらない設定です。

voiceフォルダの声は、このソフトの中で使うためのものです。取り出して使わないでください。
声がほしいときは、VOICEVOXで作ってください。

VOICEVOX:玄野武宏


■ 効果音

窓へ跳ぶとき、絵日記を描くとき、やることの紙を丸めて投げるときに、効果音を鳴らします。
メニューの「音を鳴らす」をオフにすると鳴りません。
効果音は、効果音ラボ（https://soundeffect-lab.info/）のものをseフォルダに入れてあります。
seフォルダの効果音は、このソフトの中で使うためのものです。取り出して使わないでください。

効果音：効果音ラボ


■ 着せ替え

メニューの「高度な設定」→「着せ替え」で、棒人間の頭に珠音（たまね）の髪型をのせられます。
珠音は、HSP3のオフィシャル素材のキャラクターです（著作権はオガワコウサク（チームグリグリ）氏、修正BSDライセンス）。
ドット絵の珠音をもとに、髪型だけを線と塗りで描きなおしています。どのポーズでも髪がついてきます。


■ 集中の見守り

・前面にあるアプリの名前（実行ファイル名）ごとに、使っていた時間を数えます
・ウィンドウを切り替えた回数を数えます。5分で30回をこえると、ひとこと言います
・作業中に、distract.txtに書いた語を含むウィンドウが5分続けて前面にあると、注意しに来ます（そのあと10分は来ません）
  distract.txtは1行に1語です。最初はyoutube、ニコニコ、twitch、「/ x」が入っています
  ブラウザは、いま見ているタブの題名がウィンドウのタイトルになるので、そのタブで判定します
・メニューの「サボり先を見ているあいだはタイマーを止める」をオンにすると、サボり先が前面にあるあいだは
  作業の残り時間と今日の作業時間が進みません（最初はオフ）
・メニューの「サボり先を長く開いていたら」で、続けて前面にあった時間が来たときに
  「最小化する」か「閉じる」を選べます（最初は「しない」）。時間は5・10・15・30分から選べ、
  distract.txtに「youtube=10」のように書くと、その語だけ分数を変えられます。少し前に予告します
  「閉じる」は×ボタンを押したのと同じ動きです。ブラウザはタブごと閉じ、保存していない内容は
  アプリ側の確認が出ない場合は失われることがあります
・作業中にマウスもキーも5分さわらないと呼びに来て、10分でタイマーを止めて寝ます。何か操作すると再開します
  絵を描いているときなど、止めてほしくないときは、メニューの「席を離れたら一時停止する」をオフにします
・休憩をとらずに作業2回分（25分なら50分）続けていると、伸びをして「遠くを見ると目が休まるぞ」と合図します。
  そのあとは30分ごとです。3分以上休憩するか、10分離れると数えなおします
・しばらく文字を打ち続けていると、文字カーソルのある窓の上まで来てのぞきこみます（5分に1回まで）。
  届かない高さのときは大ジャンプで飛び乗ります。メモ帳など、Windows標準の文字カーソルを使うアプリで働きます
・全画面のアプリ（ゲーム・動画）やプレゼンの最中は隠れて、声も出しません。終わると戻ってきます
・ノートPCが電池で動いているときや省電力モードのときは、描く回数を減らします


■ プライバシーについて

・キーボードは「押された回数」だけを数えます。どのキーが押されたかは、メモリにも残しません
  メニューで「タイピングを数える」を外すと、キーの状態を一切読みません
・ウィンドウのタイトルは、サボり先の語と照らし合わせるときに読むだけで、保存しません
・文字カーソルは画面上の位置だけを読みます。打った文字や画面の中身は読みません
・保存するのは、日付、回数、時間、アプリの実行ファイル名、設定だけです（settings.txt）
  教えたセリフはkotoba.txt、やることはtodo.txt、知らせる時刻はalarm.txt、日ごとの合計はhistory.txtに保存します。
  どれも外には送りません
・音楽に合わせて動く機能は、再生中の音量の数値だけを読みます。録音はせず、音の中身も読みません
・通信は、「サーバーと通信する」をオンにしたときに上の数字を送り受けするだけです（最初は参加しない設定）


■ 消しかた

フォルダごと削除してください。レジストリは使っていません。
設定画面で「Windowsの起動時に、いっしょに起動する」をオンにした場合は、
スタートアップフォルダに「作業のおとも、棒人間」のショートカットを置いています。先にオフにしてから削除してください。
settings.txtとhistory.txtを消すと、記録と設定が初期状態にもどります。
%APPDATA%\BouTimerに記録を置いていた場合は、そのフォルダも削除してください。


■ しくみ（技術的なこと）

・キャラクターは、GDI+ で32bitの画像に描き、UpdateLayeredWindowで画素ごとの半透明表示をしています。
  線はアンチエイリアスがかかり、白いふちどりで、どんな背景の上でも見えます
・ウィンドウの位置はDwmGetWindowAttribute（DWMWA_EXTENDED_FRAME_BOUNDS）で取ります。
  Windows 11の影の分のずれがありません
・手前の別のウィンドウに隠れている辺には立ちません（WindowFromPointで確認）
・投げると、見えているウィンドウの横の辺や画面の端で跳ね返ります
・「ウィンドウの裏に落ちる」動きでは、自分の重なり順を足場のウィンドウのすぐ後ろに入れかえています
・乗っているウィンドウのクラス名とタイトルからハッシュを作り、その窓での動きの並びや、拾った棒の使いみちを決めています
・線の色が「おまかせ」のときは、ウィンドウのアイコンを取り出し、鮮やかな色ほど重く平均した色にします
・音楽はWindowsのCore Audio（IAudioMeterInformation）をCOMで読み、拍の頭を拾っています
・口パクは、同梱の声といっしょに入れたVOICEVOXのaudio_query（音ごとの子音・母音の長さ）を読み、再生と時刻を合わせています
・文字カーソルの位置はGetGUIThreadInfoで取り、のぞきに行く窓までの道はダイクストラ法で探します
・全画面の判定はSHQueryUserNotificationState、電池の判定はGetSystemPowerStatusです
・CPU使用率は、論理コア1つの約5%です（論理コア20の環境で計測。PC全体では約0.3%）
